# Island Post design map

## Destination

A first-time Dock player can recover from a soaked delivery without coaching.

## Product truth

- **User:** A first-time player using touch or a keyboard.
- **Job:** Deliver a dry parcel to Mina.
- **Primary action:** Use Retry after a soaked delivery.
- **Success:** The courier returns to the fork with a dry parcel.

## Notes

The public example uses Phaser 4.2.1 and Vite. The Dock scene renders the game board and updates a native HTML result panel. Chrome and Playwright are available for browser checks. The Project Bible chapter holds accepted decisions and links to the evidence.
