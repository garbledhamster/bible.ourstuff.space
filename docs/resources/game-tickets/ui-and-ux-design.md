# Design the core interface workflow

**Chapter** 03
**Blocked by** 02

## What to build

Sketch or prototype the main workflow from the [UI & UX Design chapter](../game-bible-guide.md#ui--ux-design). Record the project’s interface standards where contributors can find them.

## Acceptance checks

- [ ] Show what the person sees, does, and gets back at each step, including how they recover.
- [ ] Use layout, spacing, and short labels to make the next action clear on the intended screen sizes.
- [ ] List the artwork for buttons, icons, HUD pieces, and frames, and the states each needs.
- [ ] Record the applicable accessibility and input checks, and define a first-time user task to try without coaching.

## Evidence and handoff

Link the sketch or prototype, its revision, the screens reviewed, and the standards it uses. Carry the required interface assets into Engine & Assets and the verification cases into the sandbox and playtests.
