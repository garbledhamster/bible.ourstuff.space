# Project Bible 2.0 Tutorial

A Project Bible brings the decisions, plans, tasks, and evidence for one project into the same place. When you come back to the work, open the current chapter and look for what you've decided, what you've checked, and what you need to do next.

The [public guide](/guide.html) teaches the chapters. Your own Bible lives in a working folder. The Desktop Manager opens that folder through a library on your computer or on another host. The Browser Client connects to a library you have access to. An agent can work alongside you in the same Bible when you give it access to the same folder or connect it to the library through MCP.

## Choose a tutorial

- **[Work Solo](solo.md).** Start a Bible, work through the chapters, and use your decisions to build and test a first release.
- **[Work With Agents](agents.md).** Give an agent the right project context, work through questions and tickets together, and review what it saves.
- **[Desktop Manager](desktop.md).** Set up a library, edit chapters, find assets, and move or recover a Bible.
- **[Browser Client](browser.md).** Sign in, pick the right host, and open, read, or edit a Bible from another device.

## Follow along with Harbor Notes

Harbor Notes is a sample project for volunteers who check a walking route and leave a record for the next crew. The tutorials use it to show an idea becoming a decision, a task, and a result you can check.

You can read every lesson here. To practice with your own copy, open your local library in the Desktop Manager and choose **Open demo**. The screenshots show sample libraries and working folders.
