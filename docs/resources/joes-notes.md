# Joe’s Notes

### Use symbols and keywords in games

Build the interface around symbols, icons, and short keywords unless the game is text-based or relies on text to play. Let players hover, focus, or press and hold to see what something means. Put longer explanations in How to Play and in the descriptions for individual items.

### Put the game’s art in its menus

Draw or generate the artwork for buttons, frames, and HUD pieces. Save those pieces with the project and use them in the game. I want to see the art when I open the menu, too. Use code to place the pieces, handle what the player does, and animate or swap the artwork. [See how the Dock does it](island-post/ui-art.md).

### Keep progress up front

Give players a way to track their progress right on the main interface. Show the resources, points, trophies, or categories that matter in that game so players can see where they stand while they play.

### Vary the layout

Look at the white space, borders, and the way text and images sit together. Try an offset layout or a slight angle where it fits. A mobile screen can be a single page if everything fits. If a site scrolls sideways, snap to each panel and keep vertical scrolling inside dialogs or other contained panels that need it.
